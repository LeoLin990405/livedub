Optimization: the core loop

梯度下降是一种一阶迭代优化算法：沿着损失函数的负梯度方向更新参数。

θ ← θ − η · ∇θL(θ)
η = learning rate · L = loss function · ∇ = gradient

Key intuition

从任意初始化点出发，重复「计算梯度 → 沿负方向走一小步」，最终到达局部极小值。
