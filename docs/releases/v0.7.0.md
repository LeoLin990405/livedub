## 界面设计优化（v0.7）

三端统一设计语言「**沉浸看课 + 学术工具**」：jade/ink 色板、短动效、低饱和高信息密度、可访问性优先。
规范文档：[docs/DESIGN.md](https://github.com/LeoLin990405/livedub/blob/main/docs/DESIGN.md)。

### 工作台
- 设计 tokens（surface/text/字号/间距/圆角/阴影/焦点环/动效）+ 统一按钮/卡片/chip/switch/segmented/toast/skeleton/dialog；
- 布局重构：紧凑顶栏 + 视频/字幕舞台 + **可折叠 dock（字幕/笔记/设置 tab rail）** + 底部统一控制条；
  ≤1100px dock 变底部 sheet、≤720px 单列；
- 笔记工作区：list+editor 双栏、过滤 chips（全部/图文/章节/总览/快捷）、章节分组、保存/离线状态、空态、Markdown 排版 + 图片 lightbox；
- **命令面板 ⌘K**（16 条命令）+ `?` 快捷键帮助；toast 堆叠；章节生成 5 步进度；replay 页统一。

### Chrome 扩展
- 字幕浮层：accent 进度线、状态 pill（识别/翻译/播放/错误 + 延迟）、译文大字/原文次级、原声 duck 指示、
  玻璃质感 + 降级、宽/紧凑两档、reduced-motion；
- 快捷面板：字幕/笔记/设置三段（aria tablist + 方向键）、分组开关、记笔记进度态、npm start 引导卡、toast 堆叠；
- popup：品牌头 + 状态 pill、主操作卡、延迟 4 格、笔记卡 + 快捷 grid、亮暗自适应；新增离线 UI 预览页。

### macOS 悬浮窗
- 浮层：jade/ink、译文 22–26pt semibold + 原文 14pt、状态 pill、accent 呼吸线、NSVisualEffectView 材质、
  亮暗自适应/降级、悬停工具条（暂停/记笔记/设置/关闭）、toast 重设计；
- **新增设置窗口**（字幕/浮层/音频/笔记与视觉/引擎，即时生效 + 恢复默认）；菜单栏分区 + SF Symbol + 快捷键提示。

### 可访问性
`focus-visible` 高对比焦点环、aria-label/tooltip、tablist/方向键、`aria-live`、
`prefers-reduced-motion` 降级、命中区 ≥32px（macOS ≥28pt）、亮暗对比度检查。

### 验证
433 tests / 424 pass / 9 skipped；macOS self-test **273/273**；`build-macos.sh --check`、`build-ocr.sh --check`、扩展 `--pack-extension` 均通过。
